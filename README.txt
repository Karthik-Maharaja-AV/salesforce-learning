ASCEND — Salesforce learning tracker

Run: python3 -m http.server 5174 --bind 127.0.0.1
Open http://localhost:5174/
Or open the standalone salesforce-learning.html in a modern browser.

Data saves to localStorage for the browser and origin you use. It does not sync across devices, ports, browsers, or the standalone file. Export JSON regularly and import to move progress. No server database or Salesforce account integration. Google Fonts is optional; system fonts work offline.

Allow extra time for experience and programming fundamentals. Official guide and trailmix links are in the Resource library.
